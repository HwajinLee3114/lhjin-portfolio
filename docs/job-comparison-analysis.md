1. **SI 풀스택 → FE 전환 스토리**: 2026 트렌드에서 "다기능 개발자"를 선호. Java/Spring 백엔드 경험을 약점이 아닌 **"풀스택 이해도"**로 리프레이밍
2. **AI 도구 활용**: Claude Code, Cursor 등 AI 코딩 도구 활용 경험을 적극 어필. 디리아 공고에서 명시적으로 요구, 다른 회사도 면접에서 확인하는 추세
3. **정량적 성과**: "이탈률 50%→20%", "전환율 15% 증가" 등은 2026 스킬 기반 채용에서 가장 강력한 무기. STAR 기법으로 구조화
4. **멀티 프로덕트 운영**: 카사요 7개 프로덕트 동시 개발/운영 = 아키텍처 설계력 + 기술적 의사결정 능력 증명

#### 약점 보완 우선순위

1. **테스트 코드 작성 능력** — 가장 많이 요구되면서 가장 약한 부분. 면접 전까지 최소한 포트폴리오에 테스트 추가
2. **"기술 리딩" 경험 어필** — 하이브랩, 토스페이먼츠 등에서 요구. 카사요에서 기술 스택 선정, 아키텍처 결정, 코드 리뷰 주도 등의 경험을 "리딩"으로 재구성
3. **브라우저/네트워크 CS 지식** — 위펀, 더그리트 등에서 면접 검증 예상. Critical Rendering Path, HTTP 캐싱, CORS 등 정리 필요
